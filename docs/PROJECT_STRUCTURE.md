# Project Structure

This repository contains the distributable TaskState Vault code and documentation. Runtime state is not committed; it is created under `.taskstate-vault/` after `init`.

## Source Tree

```text
taskstate_vault/
  Public package and implementation.

taskstate_vault/cli/
  Command-line interface.

taskstate_vault/core/
  Path resolution, JSONL/YAML-compatible IO, ids, time, events, schema, and SQLite helpers.

taskstate_vault/taskfs/
  Public TaskFS facade for initialization, status, workspace registration,
  and task-workspace link creation.

taskstate_vault/taskdb/
  Public TaskDB facade for account/domain objects, layered search,
  task imports, project-file indexing, and index rebuilds.

taskstate_vault/contextkernel/
  Public ContextKernel facade for execution modes, Project Governor,
  task lifecycle, run lifecycle, objective changes, context loading,
  and audits.

taskstate_vault/kernel/
  TaskFS initialization, task creation/opening/completion, run lifecycle,
  evidence, artifacts, errors, and task objects.

taskstate_vault/governor/
  Project Governor, project intent/model, task graph, execution queue,
  progress, objective changes, and final audit.

taskstate_vault/layers/
  Account/domain stores, layered indexes, pointer URIs, and imports into task scope.

taskstate_vault/indexing/
  Task/project index rebuild helpers and project-file indexing.

taskstate_vault/workspaces/
  Project/workspace references and task-workspace link creation.

taskstate_vault/modes/
  Execution mode detection and context profiles.

taskstate_vault/promotion/
  Promotion candidate records for reusable experience.

taskstate_vault/templates/
  System, read, write, schema, router, and usage-guide templates generated by init.

taskstate_vault/ui/
  Read-only local web UI for browsing the account index, project state,
  task graph, execution queue, tasks, runs, and TaskFS file previews.

taskstate_vault/mcp_adapter.py
  MCP-ready JSON-callable adapter and tool metadata.

taskstate_vault/vault.py
  Unified Python SDK entry point that composes TaskFS, TaskDB, and ContextKernel.

docs/
  User-facing usage and Codex setup documents.

tests/
  End-to-end tests using temporary TaskFS roots.
```

## Index Model

```text
Account index:
  .taskstate-vault/ACCOUNT/ACCOUNT_INDEX/account.sqlite

Domain index:
  .taskstate-vault/DOMAINS/<domain_id>/DOMAIN_INDEX/domain.sqlite

Project index:
  .taskstate-vault/PROJECTS/<project_id>/PROJECT_INDEX/project.sqlite

Task index:
  .taskstate-vault/PROJECTS/<project_id>/TASKS/<task_id>/INDEX/task.sqlite
```

Search order:

```text
task -> project -> domain -> account
```

Pointer URI scheme:

```text
tsv://account/<object_id>
tsv://domain/<domain_id>/<object_id>
tsv://project/<project_id>/<object_id>
tsv://project/<project_id>/task/<task_id>/<object_id>
```
